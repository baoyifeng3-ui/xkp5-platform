# py脚本说明

## 启动 T100

T100 服务运行在训练服务器上，默认根目录为题目约定的
`/home/student/zy-T100`，默认端口为 `5001`：

```bash
cd /home/student/zy-T100
T100_ROOT=/home/student/zy-T100 T100_PORT=5001 \
  python /path/to/match/python/app.py
```

推荐按卷分别部署模型：

```text
/home/student/zy-T100/utils_x86/models/A/detection.tflite
/home/student/zy-T100/utils_x86/models/B/detection.tflite
```

如果训练端只能使用旧的单模型路径
`/home/student/zy-T100/utils_x86/detection.tflite`，必须显式声明该文件所属的赛卷，不能同时冒充 A、B 两卷：

```bash
T100_SINGLE_MODEL_PAPER=A T100_ROOT=/home/student/zy-T100 \
  T100_PORT=5001 python /path/to/match/python/app.py
```

启动后可先验证部署状态：

```bash
curl 'http://127.0.0.1:5001/api/v2/checkUtils_x86?paperType=A'
```

如果使用现有 `zy-contest1` 至 `zy-contest4` 容器，端口映射是宿主机
`5001` 至 `5004` 分别转发到容器内部的 `5000`。因此必须在容器内使用
`T100_PORT=5000`；宿主机仍通过对应的 `5001` 至 `5004` 访问。
