# 统一实训切换实施与验收

用户已批准执行。复用现有 environment_operation、mode_transition 和 active_class_session，不另建重复任务系统。

1. 补充教师接管启动中/创建中环境的回归，统一同用户先停后启；保证迟到结果不能覆盖目标。
2. 后端统一提供当前模式、转换状态、课堂目标及环境操作进度，准备中禁止冲突请求，重复请求返回既有操作。
3. 删除前端按秒伪造的百分比和30秒截止，跟踪操作至真实终态，显示阶段、已用时、失败原因；教师/学生同步课堂变更并关闭旧工具。
4. 在真实浏览器定位代码工具嵌入失败，验证证书、嵌入策略、WebSocket和文件保存；必要时实现经授权的独立工具入口，避免工具脚本取得平台同源权限。
5. 构建并部署。双角色浏览器与API共同验证自由实训、课程、教师接管、比赛往返、快速操作、断线、失败与重试；以数据库、Docker、页面一致为通过标准。
6. 只删除本轮明确命名的临时环境，保留用户新建的正式课程/实训环境；记录报告、覆盖更新当前状态，报告未测边界。
