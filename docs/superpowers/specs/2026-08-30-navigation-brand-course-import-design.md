# 导航、品牌设置与课程批量导入设计

## 目标

统一三类用户界面的侧边导航布局，完善平台品牌配置并修复登录背景显示；将指定电子书目录批量导入为平台课程与章节。

## 导航

- 主菜单、普通菜单和分组菜单使用相同高度、左右边距、图标宽度和文字起始线。
- 子菜单文字与主菜单文字对齐，不再贴近侧栏左边缘。
- Element UI 菜单启用唯一展开模式；展开新分组时自动收起旧分组。
- 主页与其他一级菜单保持相同宽度、圆角和行高。
- 响应式折叠状态保持现有图标模式，不更改路由和角色权限。

## 品牌设置

- 平台设置新增 Logo 上传、预览和移除。
- Logo 同时用于登录页和工作台侧栏；未设置时保留当前默认圆形标志。
- 登录页英文副标题由固定文本改为可配置字段，默认值保持 `XKP5.0 MANAGEMENT PLATFORM`。
- 现有中文名称、主标题、说明、版权和主题色继续可配置。
- Logo 与背景图片复用当前文件存储和 `/files/**` 代理，不新增存储系统。
- 上传成功后先本地预览，点击保存才写入平台设置；重新登录和刷新后仍显示。
- 背景图片使用后端公开代理 URL，登录页面采用 `cover` 显示，并保留可读的遮罩层。

## 课程导入

输入根目录：

`C:\新建文件夹 (5)\文件\产品\人工智能\安装部署\MGR9000\download\电子书`

已扫描数据：9 个类别、43 门课程、585 个 PDF、约 2.06 GiB。

导入映射：

- 第一层目录是一种课程类别，移除类似 `01类 ` 的前置编号。
- 第二层目录是一门课程，移除类似 `01 ` 的前置编号。
- 每门课程单独创建并默认启用，普通用户可见。
- 每个 PDF 创建一个章节，章节名取不含扩展名的文件名。
- PDF 同时作为该章节的电子书资源上传。
- 视频、PPT 和课程数据暂不创建占位资源。
- 章节按自然文件名排序，保证 `第2章` 位于 `第10章` 前。
- 导入按“类别+规范化课程名”幂等；已存在的同名课程不重复创建，缺失章节可补录。
- 单个文件失败时记录课程、文件和错误，继续导入其他课程；结束后输出成功、跳过和失败数量。
- 原文件只读，不移动或删除。

## 实现边界

- 导航和品牌沿用现有 Vue 2、Element UI、Vuex 与 Spring Boot 设置服务。
- 为系统设置增加 `platformLogoUrl` 和 `loginEnglishSubtitle` 两个字段，不引入新表。
- 课程导入使用本地管理脚本调用现有课程创建、章节创建和资源上传接口，避免绕过业务校验直接写数据库。
- 导入脚本保留为运维工具，支持 `--dry-run` 和正式执行两种模式。

## 验证

- 管理员、超级管理员、普通用户分别检查一级/二级菜单对齐与唯一展开。
- 上传 Logo 和背景后保存、刷新、退出再登录，确认图片与英文副标题持久显示。
- 验证 `/files/**` 返回正确图片 MIME 类型和 HTTP 200。
- 先 dry-run 核对 9 类、43 门、585 个 PDF，再执行导入。
- 导入后对比数据库/接口统计，并抽查不同类别课程的章节数、PDF 在线预览和普通用户可见性。
