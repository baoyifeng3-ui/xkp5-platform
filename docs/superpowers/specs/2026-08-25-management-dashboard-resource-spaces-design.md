# 管理主页、模式切换与资源空间设计

## 目标

本次改造统一解决普通用户模式分流、普通管理员主页业务操作、服务器实时资源监控，以及课程资源和平台文件空间无法正常上传、关联与管理的问题。

## 角色与入口

### 普通用户

- 平台处于实训模式时，登录后进入 `/course-platform`。
- 平台处于比赛模式时，登录后进入 `/Publicity`，并使用完全隔离的比赛界面。
- 路由守卫禁止普通用户访问当前模式之外的界面。
- 普通用户不显示课程资源库。

### 普通管理员

- 登录后进入 `/management` 主页。
- 负责进入或退出比赛模式及实际业务管理。
- 主页显示比赛模式切换按钮，点击后只弹出确认框，不要求输入确认短语，不跳转页面。
- “模式与环境”菜单、路由和页面全部删除。
- “比赛账号与容器绑定”菜单改名为“比赛环境”，现有账号与槽位绑定功能不改变。

### 超级管理员

- 登录后进入 `/operations` 运维主页。
- 只负责平台维护，不显示业务模式切换按钮。

## 普通管理员主页

主页采用已确认的 A“运维总览型”布局。

### 顶部状态

- 当前平台模式：实训模式或比赛模式。
- 平台总用户数：包含超级管理员、普通管理员和普通用户。
- 当前在线用户数：复用用户会话活动统计口径。
- 比赛模式切换按钮根据当前状态显示“进入比赛模式”或“退出比赛模式”。

### 用户统计

删除原“平台联系人”区域，替换为用户统计。至少显示总用户数、在线用户数和离线用户数。

### 服务器资源监控

- 复用处理服务器 Agent 上报的最新指标，在现有主页总览接口中返回逐台服务器数据。
- 页面每 5 秒刷新一次，不并发调用多个无关接口。
- 每台服务器显示：名称或 Agent ID、在线状态、CPU、GPU、内存、磁盘、网络上传速率、网络下载速率、运行容器数和最后上报时间。
- 离线服务器仍保留在列表中，显示最后一次指标并明确标记离线。
- 没有上报的指标显示 `--`，不能伪造为 0。

### 保留功能

- 保留课程、资源、实训环境等快捷入口。
- 保留“一键上课”对话框和现有课程环境启动逻辑。

## 资源数据模型

平台文件统一使用目录、文件和空间模型，底层文件只存储一次。

### 空间类型

- `COURSE`：课程资源库。
- `PUBLIC`：公共资源库。
- `EXCHANGE`：交换空间。
- `HOMEWORK`：用户私有作业空间。

### 核心实体

- 目录：空间类型、父目录、目录名称、创建人、创建时间。
- 文件：空间类型、目录、文件名、存储键、大小、MIME 类型、SHA-256、上传人、创建时间。
- 课程资源关联：课程 ID、文件 ID、资源类型、排序、启用状态。

目录使用父目录 ID 表达多级结构。文件权限由空间类型和上传人共同决定，不能依赖前端隐藏按钮实现授权。

### 迁移

- 现有 `course_resource` 数据迁移为 `COURSE` 空间文件和课程关联记录。
- 现有课程学习进度及下发记录继续引用稳定的资源标识，迁移不得丢失历史数据。
- 迁移后同一个课程资源文件可关联多门课程，不复制底层文件。

## 四类资源空间

### 课程资源库

- 仅管理员可见。
- 支持上传、删除、下载、创建目录和关联课程。
- 资源类型包括电子书、PPT、视频、压缩包或课程数据。
- 上传时必须至少关联一门课程，后续可继续关联其他课程。
- 删除文件前检查课程引用；仍被课程引用时禁止删除，并返回引用课程名称。
- 课程管理的“添加内容”支持上传新文件并自动关联当前课程，也支持选择课程资源库中的已有文件。
- 从课程中移除资源只删除关联，不删除文件本体。

### 公共资源库

- 管理员可创建多级目录、上传和删除文件。
- 普通用户可浏览目录、下载文件到本地，也可发送到自己的实训容器。
- 普通用户不能上传、删除或修改公共资源。

### 交换空间

- 管理员和普通用户都可以创建多级目录和上传文件。
- 所有平台用户可以查看及下载交换空间文件。
- 普通用户只能删除自己创建的目录和自己上传的文件。
- 管理员可以操作交换空间全部目录和文件。
- 管理员可通过“一键清空”清除整个交换空间。

### 作业空间

- 每个普通用户拥有独立的私有作业空间，支持多级目录、上传、下载和删除。
- 所有文件查询强制限定当前登录用户，其他普通用户无法查看。
- 管理员和超级管理员都不能查看文件名、目录、所属用户或文件内容。
- 管理员主页只可获得作业空间总文件数和总容量。
- 管理员“一键清空作业空间”清除全部用户作业文件，但清空接口和审计记录不能泄露用户或文件明细。

## 上传、下载与删除

### 上传

- 页面显示文件名、大小、上传百分比和失败原因。
- 上传完成后服务端计算并保存 SHA-256、大小和 MIME 类型。
- 数据库记录创建失败时，必须清理已上传但未引用的文件，避免孤儿文件。
- 上传成功后自动刷新当前目录和课程资源列表。

### 下载与发送容器

- 课程资源只允许管理员从课程资源库下载；普通用户通过课程界面在线学习，不能下载课程资源到本地。
- 公共资源和交换空间文件允许普通用户下载到本地。
- 公共资源可发送到当前用户自己的实训容器。
- 作业空间文件仅所属用户可下载。

### 删除

- 删除文件、目录和一键清空均由后端再次执行权限校验。
- 非空目录不能直接删除，除非调用明确的一键清空操作。
- 课程资源有引用时拒绝删除文件本体。
- 一键清空交换空间或作业空间必须二次确认，并记录操作者、空间、文件数量、总容量和时间，不记录作业文件明细。

## 接口与错误处理

- 主页总览接口增加 `totalUsers`、当前模式和逐台 Agent 资源列表。
- 模式切换复用平台模式服务，普通管理员有权调用，超级管理员不参与业务操作。
- 资源接口按空间拆分查询权限，所有对象查询必须同时校验空间和角色。
- 资源不存在返回明确的 404 业务错误；无权限返回 403；课程引用冲突返回 409。
- 上传失败、容器不可用和存储服务不可用使用明确中文提示，不能统一显示“请求失败”。

## 刷新与并发

- 主页服务器指标每 5 秒刷新。
- 模式切换期间按钮禁用，防止重复提交。
- 文件上传期间禁用重复提交，目录和资源列表只在成功后刷新。
- 同一文件的课程关联使用唯一约束避免重复关联。
- 一键清空在事务内生成审计汇总，并使用空间级操作锁避免与上传并发产生不确定结果。

## 验收标准

1. 实训模式和比赛模式下，普通用户登录分别进入对应且互相隔离的界面。
2. 普通管理员可在主页确认后切换模式，页面不跳转；超级管理员不显示该操作。
3. “模式与环境”菜单、路由和页面不存在；绑定菜单显示为“比赛环境”。
4. 主页显示准确的总用户数、在线数及逐台服务器完整资源指标。
5. 课程创建后可以上传新资源或选择课程资源库已有资源，保存后普通用户课程中可见。
6. 课程资源库、公共资源库、交换空间和作业空间权限符合本设计。
7. 公共资源、交换空间和作业空间支持多级目录。
8. 交换空间普通用户不能删除他人文件；管理员可以管理并清空全部。
9. 管理员无法查看作业空间明细，但可查看汇总并清空全部作业空间。
10. 所有上传、下载、关联、删除和清空操作都有成功状态及明确错误信息。

## 测试策略

- Java 单元测试覆盖模式权限、登录分流、用户统计、Agent 指标解析、空间权限、课程关联、目录隔离和清空审计。
- 数据库迁移测试覆盖旧课程资源迁移、多课程关联唯一约束和空间字段约束。
- Vue 契约测试覆盖菜单删除/改名、主页模式按钮、服务器指标、四空间导航和上传控件。
- API 集成测试分别使用超级管理员、普通管理员和两个普通用户验证权限边界。
- 浏览器测试覆盖桌面及移动视口，检查主页表格、资源目录、上传进度和确认对话框无重叠。
