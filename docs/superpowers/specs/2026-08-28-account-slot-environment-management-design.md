# 账号槽位与实训环境管理设计

## 目标

简化管理员创建实训环境的操作：服务器和槽位只在账号创建或迁移时绑定，后续创建默认环境、课程环境或比赛环境时只选择账号。平台负责解析账号绑定、校验服务器与镜像、分配端口并创建容器。

同时完善普通账号的单个与批量管理、首次改密、比赛临时密码、服务器槽位迁移以及环境端口池管理。

## 核心原则

1. 每个普通账号只能绑定一台处理服务器的一个槽位。
2. `processing_environment_slot.user_id` 是账号与服务器槽位绑定的唯一事实来源。
3. 槽位表示账号的服务器归属，不限制账号可创建的环境数量。
4. 一个账号可以拥有一个默认环境、多个课程环境和比赛环境。
5. 每个环境独立分配端口；停止环境不释放端口，删除环境才释放。
6. 同一账号任意时刻最多运行一个图像标注容器和一个代码编辑容器，允许二者均不运行。
7. 实训环境创建接口不再接受服务器和槽位，由后端从账号绑定解析。

## 数据模型

### 账号资料

继续使用 `user` 表保存登录身份和密码状态，增加普通账号备注字段。账号级自定义字段沿用现有键值对机制，支持每个账号保存不同字段，例如班级、学号和院系。

账号视图增加：

- 备注；
- 绑定服务器 ID、名称与 IP；
- 绑定槽位 ID 与槽位编号；
- 环境数量；
- 是否具备创建环境条件；
- 比赛模式下的临时密码状态。

### 槽位绑定

账号创建和更新时在事务内锁定处理服务器槽位：

- 槽位必须存在、未绑定且服务器已启用；
- 一个账号只能绑定一个槽位；
- 一个槽位只能绑定一个账号；
- 批量创建时按所选服务器、槽位编号顺序分配空闲槽位；
- 创建数量不能超过所选服务器空闲槽位总数。

### 环境端口分配

端口分配记录从“仅关联槽位”升级为明确关联环境，并保留账号槽位和服务器信息用于查询。数据库对 `(agent_id, host_port, protocol)` 建立唯一约束。

默认端口池如下，每类 500 个端口，超级管理员可在平台设置中按服务器覆盖：

| 环境类型 | 工具 | 默认范围 |
| --- | --- | --- |
| 课程 | 图像标注 | 20000-20499 |
| 课程 | VS Code | 20500-20999 |
| 课程 | Jupyter | 21000-21499 |
| 课程 | T100 | 21500-21999 |
| 比赛 | 图像标注 | 22000-22499 |
| 比赛 | VS Code | 22500-22999 |
| 比赛 | Jupyter | 23000-23499 |
| 比赛 | T100 | 23500-23999 |

现有已分配端口继续有效。新环境从扩展端口池原子分配：图像标注占用一个端口；代码编辑占用 VS Code、Jupyter、T100 三个端口。端口不足时只拒绝受影响账号，并返回具体池容量错误。

### 比赛临时凭据

新增比赛凭据记录，按账号和比赛模式代次保存：

- 进入比赛前的原密码存储值；
- 比赛临时密码的登录存储值；
- 可供管理员查看的加密临时密码；
- 生成时间、修改时间和模式代次。

临时密码明文使用平台密钥加密，不以明文长期存入数据库。退出比赛模式后恢复原密码并清除本轮临时凭据。

## 账号管理流程

### 单个创建

管理员必须填写用户名、初始密码、备注、绑定服务器和绑定槽位，可以添加任意账号级自定义键值字段。用户名和槽位绑定均在同一事务内校验。

### 批量创建

管理员选择一台或多台服务器和创建数量。平台按服务器与槽位顺序自动分配，生成 `userN` 用户名和 6 位随机初始密码。初始密码使用排除易混淆字符后的字母与数字，账号设置 `must_change_password=true`。

结果页显示并支持导出：用户名、初始密码、服务器、槽位和备注。随机密码只在创建结果与受控导出中展示。

### 日常维护

账号管理支持：

- 单个和批量启用；
- 单个和批量禁用；
- 单个和批量删除；
- 修改用户名、密码、备注和自定义字段；
- 更换服务器槽位；
- 按用户名、备注、自定义字段、服务器、绑定状态和启用状态过滤。

账号存在任何默认、课程或比赛环境时禁止直接删除，必须先删除环境。比赛模式中禁止删除账号或迁移槽位。

## 服务器槽位迁移

修改已创建账号的服务器或槽位时进入环境迁移流程。迁移请求默认不迁移用户数据，可勾选“迁移用户数据”。

流程如下：

1. 锁定账号、原槽位和目标槽位，禁止新的环境操作和模式切换。
2. 校验目标服务器在线、目标槽位空闲。
3. 读取账号所有默认环境、课程环境和比赛环境的模板版本、镜像摘要与环境配置。
4. 校验目标服务器已存在相同不可变摘要的镜像；任一镜像缺失或版本不同则停止迁移并提示先推送。
5. 若选择数据迁移，复制账号工作目录到目标服务器并校验大小与摘要。复制失败时不切换槽位。
6. 停止并删除原服务器上的账号容器，释放原环境端口。
7. 将账号绑定切换到目标槽位。
8. 从目标服务器端口池重新分配端口。
9. 按原模板版本、环境类型和配置重新创建所有环境。
10. 全部成功后完成迁移并释放原槽位。

迁移记录保存每个阶段、错误和重试状态。失败时账号标记为“迁移失败”，不能作为环境创建候选或启动容器。平台提供继续迁移和恢复到原服务器操作。

## 实训环境创建

管理员创建环境时只选择：

- 环境类型；
- 环境名称与备注；
- 一个或多个账号；
- 可选课程；
- 图像标注模板和/或代码编辑模板。

账号列表只返回满足以下条件的普通账号：

- 账号启用；
- 已绑定有效服务器槽位；
- 处理服务器在线且启用；
- 账号不处于迁移中或迁移失败；
- 当前模式允许创建该环境类型。

界面提供“全选当前可用账号”，并显示每个账号的只读服务器与槽位摘要。后端逐账号解析绑定、校验镜像、分配端口并创建环境。批量请求中某个账号失败不回滚其他账号，响应包含逐账号结果。

## 比赛密码生命周期

进入比赛模式时，对全部启用普通账号生成新的 8 位随机密码。字符集包含大小写字母和数字，并排除 `0/O、1/I/l` 等易混淆字符。

流程如下：

1. 保存每个账号进入比赛前的密码存储值。
2. 生成、加密保存并启用比赛临时密码。
3. 管理员可查看和导出本轮比赛账号密码清单。
4. 管理员可修改单个账号比赛密码，或重新随机生成。
5. 每次重新进入比赛模式均生成全新密码，不复用历史密码。
6. 退出比赛模式时恢复原密码，撤销比赛会话并清除本轮临时凭据。
7. 模式切换失败或回滚时同步恢复原密码，不能留下半切换账号。

普通账号在比赛模式使用比赛密码登录；退出比赛模式后比赛密码立即失效，继续使用原实训密码。

## 管理界面

账号管理首页显示总账号、启用、禁用、已绑定和可用账号统计。列表显示账号、备注、服务器、槽位、环境数量、状态和首次改密状态。

工具栏提供：

- 创建账号；
- 批量创建；
- 批量启用；
- 批量禁用；
- 批量删除；
- 比赛模式下导出比赛密码。

编辑账号更换槽位时显示环境迁移确认页，“迁移用户数据”默认关闭，并展示镜像预检、环境数量和预计端口需求。

服务器资源页面增加各端口池的总量、已用、剩余和冲突状态。

## 错误与一致性

- 数据库唯一约束和事务锁共同防止账号或槽位重复绑定。
- 端口池分配使用服务器级事务锁，禁止重复端口。
- 环境、迁移或比赛密码状态不完整时拒绝用户启动环境。
- 批量操作返回逐账号结果，不使用单条模糊错误覆盖整批结果。
- 所有密码生成、查看、修改、恢复和导出写入审计日志。
- 管理员不能通过普通账号管理接口修改平台管理员账号。

后端测试覆盖：

- 单个账号创建与槽位唯一性；
- 批量账号命名、6 位随机密码和首次改密；
- 启用、禁用和删除保护；
- 自定义字段读写；
- 环境候选账号过滤与全选结果；
- 创建环境自动解析服务器槽位；
- 多环境端口分配、释放和池耗尽；
- 同账号最多运行一个同类容器；
- 槽位迁移镜像预检、可选数据迁移、失败恢复和环境重建；
- 比赛密码生成、修改、重新生成、原密码恢复和模式失败回滚。

前端测试覆盖：

- 单个与批量创建表单；
- 账号批量选择和批量状态操作；
- 槽位迁移确认与数据迁移默认关闭；
- 环境账号过滤、全选和逐账号结果；
- 比赛密码查看、修改、重新生成和导出；
- 端口池容量展示。
