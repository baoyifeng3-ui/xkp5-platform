# 实训环境组策略设计

## 目标

按环境名称汇总管理页面，并实现课程、默认环境和一键上课之间的容器访问策略。

## 规则

- 图像标注为独立容器，使用唯一系统端口，用户不选端口。
- 代码编辑为独立容器，VS Code 和 Jupyter Notebook 是该容器的两个访问端口。
- 每个用户同时最多运行一个图像标注和一个代码编辑容器，也可以都不运行。
- 切换默认环境与课程环境时，先停止该用户当前环境组，再启动目标环境组。
- 课程与默认环境可只配置一个组件，启动时只启动已配置的组件。
- 一键上课保存课程和代码工具策略；选课程时用户只能访问该课程已绑定的环境。不选课程时使用用户的默认环境。

## 实现范围

保留现有每个用户一条 `training_environment` 记录和现有端口分配，在查询层按 `environment_name` 分组，不新增容器共享。一键上课会话扩展已有的 `active_class_session`，用于记录课程和代码工具，权限校验只在后端执行。
