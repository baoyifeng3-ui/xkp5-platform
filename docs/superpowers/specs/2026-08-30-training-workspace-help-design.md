# 实训工作区、课堂限制与在线帮助设计

## 目标

扩大平台业务页面的有效内容区，重构实训工作区交互，补齐临时数据集上传、模型部署、多文件上传、课堂功能限制、课程展示、登录背景和分角色在线帮助。

## 页面空间与实训布局

- 所有业务页面的主要内容区使用浏览器剩余宽度和高度，减少固定尺寸造成的空白。
- 实训页面使用紧凑控制栏：环境选择、状态、课程信息和可用工具横向排列。
- 快捷栏包含刷新、全屏、模型验证、实训报告、数据集上传和模型部署。
- 实训 iframe 填满剩余视口空间。
- 全屏模式隐藏平台页头、侧栏和环境摘要，只保留快捷栏和实训工具。
- 半屏课程模式使用可拖动分隔栏，课程资料与实训工具可自由调整大小。
- 实训报告可随时打开、收起、缩放和调整大小。

## 一键上课策略

### 未上课

- 普通用户可以正常使用课程平台、实训环境、模型验证和资源功能。
- 用户可启动默认独立环境，或从课程章节启动课程绑定环境。

### 上课中

- 普通用户只允许进入实训环境和模型验证。
- 访问课程平台、资源中心等其他功能时显示“当前上课中，禁止使用该功能”。
- 普通管理员与超级管理员不受普通用户课堂路由限制。

### 独立环境课堂

- 用户进入实训页面后直接打开管理员选择的独立环境。
- 快捷栏只显示该环境实际存在的图像标注和代码组件。
- 管理员选择 VS Code 后用户不能切换 Jupyter，选择 Jupyter 时同理。

### 课程课堂

- 用户进入实训页面后首先显示管理员指定课程的章节目录。
- 用户可查看该课程章节提供的 PPT、视频、电子书和其他在线资料。
- 用户只能打开课程或章节已绑定的实训环境。
- 打开章节环境后可在全屏和可调整大小的半屏模式之间切换。

## 文件上传与中转

### 实训数据集

- 实训页支持多文件选择，上传目标为 `/home/student/data/datasets`。
- 文件只进入平台临时中转区，不写入用户资源空间。
- Agent 通过一次性凭据下载文件，成功后平台立即删除临时文件。
- 失败文件保留 24 小时，用于自动或手动重试，随后自动清理。

### 资源与课程文件

- 资源管理支持多文件上传，每个文件独立显示进度、成功和失败状态。
- 资源管理上传的文件永久保存在对应资源空间。
- 其他发送到实训环境的文件统一写入 `/home/student/data`。
- 已存在的课程或公共资源发送时复用原文件，不创建新的平台副本。

## 模型部署

- 用户可浏览当前代码容器的 `/home/student` 及全部子目录。
- 用户分别选择一个模型文件和一个配置文件。
- 不允许浏览 `/home/student` 之外的容器系统目录。
- 文件复制到 `/usr/local/zy-T100/utils_x86/models/A`。
- 目标存在同名文件时必须二次确认后覆盖。
- 部署操作记录操作者、环境、源路径、目标路径、时间和结果。
- 普通用户只能部署到自己的环境；管理员演示入口可以部署到当前所选用户环境。

## 课程平台

- 普通用户和管理员演示入口使用同一套课程数据转换，避免角色页面字段不一致。
- 普通用户只看到已发布课程；管理员演示入口可用管理员身份查看并操作演示内容。
- 无课堂限制时两种角色均能看到课程、章节和资源。
- 空列表必须说明原因：暂无已发布课程，或当前课堂仅允许指定课程。

## 登录背景

- 背景上传结果转换为平台同源可访问地址，设置预览与登录页使用同一个地址。
- 保存前检测图片可访问性；不可访问时拒绝保存。
- 支持 JPEG、PNG 和 WebP，单文件最大 10 MB。

## 在线帮助

- 维护“用户帮助”和“管理员帮助”两类文档。
- 超级管理员可以新建、编辑、上传、发布和停用文档。
- 普通管理员可查看管理员帮助和用户帮助。
- 普通用户只能查看已发布的用户帮助。
- 富文本支持标题、字号、粗体、斜体、颜色、列表、引用、链接、表格、图片和基础排版。
- 正文图片上传到平台文件存储，正文只保存图片地址。
- PDF 可在平台内预览；DOC/DOCX 提供下载，不做在线转换。
- 三类角色的一级菜单均提供在线帮助入口，内容由后端权限控制。

## 任务状态与错误处理

- 上传、转发和模型部署任务使用等待、上传中、处理中、成功、失败状态。
- 页面刷新后从后端恢复任务状态。
- 浏览器到平台上传失败支持断点继续；Agent 下载失败支持重新派发。
- 模型部署前检查源文件、目标目录、文件名和写权限。
- 一键上课策略由后端提供，前端路由和后端接口同时校验。

## 验证标准

- 普通用户和管理员均能看到符合权限的课程、章节和资源。
- 上课状态下普通用户只能使用管理员指定的实训和模型验证功能。
- 独立环境和课程环境均正确限制可用组件和代码工具。
- 实训页正常、全屏和半屏布局在桌面与移动宽度下不重叠。
- 多文件上传逐文件显示进度并可重试。
- 临时数据集成功转发后不出现在资源空间，失败文件 24 小时后清理。
- 模型文件按确认规则复制到 T100 目录，越界路径被拒绝。
- 背景图片保存后重新打开登录页可以显示。
- 三类角色只能查看各自允许的帮助文档。
- 自动测试通过后，在两台处理服务器上各验证一个真实环境。
