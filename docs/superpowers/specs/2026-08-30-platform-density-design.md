# 平台页面比例优化设计

## 目标

减少管理端、普通用户端和超级管理员端页面的无效空白，让列表、卡片、监控和实训工具使用更多可用屏幕空间，同时保持表单和移动端的可读性。

## 公共比例

- 桌面端主内容区内边距由 `20px 24px 26px` 收紧到 `14px 16px 18px`。
- 桌面端页面顶部统一为约 `40px` 的紧凑栏：面包屑与页面级操作按钮同排显示，不再保留隐藏标题形成的空白区。
- 没有页面级操作的页面只显示单行面包屑；页面内部章节标题、工具标题和表格标题不受影响。
- 移动端顶部栏允许换行，操作按钮保持可点击尺寸且不产生横向溢出。
- 页面主要区块间距统一在 `12px` 到 `16px`，减少连续空白带。
- 平板和移动端继续使用现有 `12px` 内容边距与单列布局，不压缩触控目标。

## 宽屏布局

- 课程卡片、统计卡片等重复内容使用 `auto-fit/minmax`，宽屏自动显示更多列。
- 表格、监控、镜像仓库和实训工作区取消不必要的 `1120px`、`1180px`、`1400px` 页面最大宽度。
- 数据型页面内容宽度保持 `100%`，并使用剩余视口高度，避免表格下方大块空白。
- 空状态区域使用响应式最小高度，不以固定大高度撑开小数据页面。

## 保持约束

- 平台设置、账号编辑、课程编辑等表单不强制铺满整行；表单最大宽度扩大到约 `840px`，避免超宽输入框。
- 图片预览、Logo 预览和弹窗保持稳定尺寸。
- 不修改业务逻辑、接口、权限、菜单和数据结构。
- 不改变课程详情与实训工作区已有的可拖动分屏规则。

## 验证

- 公共 UI 契约检查桌面内容边距、面包屑高度与响应式卡片网格。
- 前端生产构建通过。
- 浏览器在 1440×900、1024×768 和移动宽度下抽查主页、课程管理、资源管理、实训管理、镜像仓库和平台设置。
- 确认页面无横向溢出、操作按钮不重叠、表单输入区域不过度拉伸。
