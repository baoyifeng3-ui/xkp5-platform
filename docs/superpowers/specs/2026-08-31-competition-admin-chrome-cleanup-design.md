# 比赛管理重复界面清理设计

## 目标

删除比赛管理页面中与平台公共外壳重复的导航、账号状态和页面标题区域，让比赛控制、赛规赛程、试卷题目和试卷评分直接展示业务内容，同时保留关键操作按钮。

## 比赛端菜单

- 从比赛模式普通用户侧边菜单删除“比赛实操”入口。
- 保留现有比赛实操路由、接口和组件，避免影响已有环境数据与兼容入口。
- 管理员比赛管理菜单不新增或移动其他功能。

## 管理页面

- 删除 `Admin.vue` 内层的“管理中心 / 当前页面”导航。
- 删除内层状态同步、管理员身份和修改密码栏；平台公共顶栏继续负责账号和退出操作。
- 隐藏比赛控制、赛规赛程、试卷题目和试卷评分的重复大标题与说明文字。
- 保留刷新比赛状态、保存内容、清空记录、比赛帮助、新增题目、导出试卷等业务按钮。
- 关键按钮使用紧凑操作栏靠右显示，业务内容紧接平台面包屑下方。

## 保持约束

- 不修改比赛计时、赛卷选择、题目编辑、评分和导出逻辑。
- 不修改接口、数据库、权限和模式切换逻辑。
- 首次登录必须修改密码的拦截页面继续保留。
- 移动端关键按钮允许换行，不隐藏危险操作按钮。

## 验证

- 导航契约确认比赛端不再显示“比赛实操”。
- 管理界面契约确认重复的 `admin-utility` 被移除，关键操作方法和按钮仍存在。
- 前端生产构建通过。
- 比赛控制、赛规赛程、试卷题目和试卷评分页面无重复顶部区，关键按钮可见。
