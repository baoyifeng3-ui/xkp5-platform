# 课程学习工作区设计

## 目标

把普通用户课程详情页改造成同页学习工作区。课程资料不再使用小弹窗预览；用户进入实训时不离开课程页，而是在当前页面同时查看课程资料和操作实训环境。

## 页面状态

课程详情页包含三种状态：

1. **课程目录状态**：显示课程简介、大纲、目录、PPT、视频和数据资源。
2. **资料预览状态**：点击在线浏览后，在课程页内容区完整显示 PDF、PPT 或视频，不使用固定宽度弹窗。
3. **分屏实训状态**：点击进入实训后，左侧显示当前课程资料，右侧嵌入实训环境；不发生路由跳转。

从资料预览或分屏状态可以返回课程目录，且保留当前课程选择。

## 工作区布局

桌面端使用左右分屏：

- 左侧为课程资料区，初始宽度约三分之一。
- 右侧为实训工具区，占据其余空间。
- 中间使用可拖动分隔线，限制最小宽度，避免任一侧无法操作。
- 窄屏自动切换为上下布局，分隔线改为上下拖动。

资料预览状态下，资料区占满课程内容宽度。全屏使用浏览器原生 Fullscreen API，只保留工作区和顶部快捷工具栏，隐藏平台侧栏和页头。

## 顶部工具栏

分屏实训状态的顶部工具栏提供：

- 实训环境下拉选择。
- 图像标注、VS Code、Jupyter 工具切换。
- 刷新当前嵌入工具。
- 进入或退出全屏。
- 打开或收起实训报告。
- 返回课程目录或关闭实训工作区。

工具按钮只在当前环境提供对应 URL 时可用。图像标注直接使用图像标注端口；VS Code 使用容器内 9090 对应的外部端口；Jupyter 使用容器内 8888 对应的外部端口。

## 环境启动与数据流

课程页复用现有实训环境 API 和 URL 字段，不新增容器启动协议：

1. 加载当前账号可用环境。
2. 优先筛选与当前课程绑定的环境。
3. 用户选择环境或点击工具时，若环境未运行，则调用现有启动接口。
4. 启动期间显示“环境正在启动”，并刷新环境状态。
5. URL 就绪后在右侧 iframe 中打开选定工具。

环境启动失败不会影响课程资料预览。页面保留错误提示和重试入口，不自动跳转到独立实训管理页。

## 课程资料预览

- PDF、PPT 使用现有预览 URL 嵌入 iframe。
- 视频使用原生 video 控件并支持浏览器全屏。
- 数据资源仍提供发送到当前实训环境的操作。
- 学习进度继续使用现有课程进度接口记录。
- 切换课程资料不会重新启动已经运行的环境。

## 实训报告

实训报告改为工作区内浮动编辑窗：

- 可拖动、可缩放、可最小化和重新打开。
- 不替换课程资料或实训环境。
- 继续按课程保存内容，并自动保存。
- 保留文字格式、图片插入、导出文档、上传交换空间和上传作业空间功能。
- 浮窗不能遮住顶部工具栏，最小尺寸保证编辑控件可用。

## 实现边界

前端复用已有课程、实训环境、数据集上传、模型部署和实训报告接口。仅在课程详情页组合现有能力，不修改容器创建、端口分配、权限和一键上课规则，降低对已测试功能的影响。

## 错误处理

- 无课程环境：显示当前课程未绑定实训环境，不离开课程页。
- 环境启动中：显示状态并禁止重复提交启动命令。
- 工具 URL 未就绪：工具按钮禁用或提示稍候。
- iframe 加载失败：保留刷新和切换工具操作。
- 资料预览失败：显示资源名称和重试入口，其他资料仍可打开。

## 验证

- 契约测试确认课程页不再通过路由跳转进入实训。
- 契约测试确认环境选择、工具切换、可拖动分隔线、工作区全屏和报告浮窗存在。
- 前端生产构建通过。
- 浏览器验证 PDF 全宽预览、左右分屏拖动、三种工具切换、全屏和报告浮窗。
- 回归课程进度记录、数据资源发送和独立实训页面。
