# 一键上课资源中心与登录背景设计

## 一键上课资源中心

- 普通用户在一键上课期间可以进入资源中心。
- 资源中心保留现有用户权限：浏览资源、下载允许下载的内容、发送资源到当前实训环境。
- 指定课程、实训环境和模型验证的现有上课规则保持不变。
- 课程列表及其他未授权页面仍显示“当前上课中，禁止使用该功能”。
- 导航点击与直接输入 `/resource-center` 地址使用同一白名单规则。

## 登录背景

- 自定义背景图保持 `cover` 显示。
- 深色遮罩从 70% 调整为 35%，提高图片可见度。
- 顶部品牌文字继续使用白色，不移除遮罩，避免浅色背景导致文字不可读。

## 验证

- 一键上课期间可从菜单和直接地址进入资源中心。
- 其他非白名单页面仍被拦截。
- 无自定义背景时页面样式不变。
- 自定义背景遮罩使用 `rgba(26, 34, 55, .35)`。
