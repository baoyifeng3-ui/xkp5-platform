# 实训、比赛、课堂与 Agent 联合修复验收

后续用户浏览器复测发现代码页面证书与切换提示问题；本文只记录此前阶段的检查，不能作为当前完整验收结论。最新进展及未通过项目见 `UNIFIED_SWITCH_QA_2026-09-10.md`。

日期：2026-09-10。验证范围为本机 stable 平台与 xt-01、xt-02、xt-03。

## 已确认并修复的问题

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 两个镜像显示成四个 | Docker 标签逐条展示，部分标签又映射为上传文件名 | 按完整镜像 ID 合并展示及计数；所有标签保留在同一行 |
| 最新 Agent 仍允许升级 | 前端目标版本写死且只判断相等；后端无升降级校验 | 后端统一返回目标版本及升级资格；按数字段比较，只允许升级；刷新同步当前选中服务器 |
| 已提交创建但没有容器 | xt-01 缺少编辑器证书；xt-02 的证书文件路径是目录 | 签发匹配服务器 IP 的证书并修复安装；错误目录备份；安装脚本使用 `install -T`，防止把文件误装进同名目录 |
| 创建结果不显示最终失败 | 弹窗只显示提交结果，环境列表缺少操作错误 | 后端返回最近操作状态和原因；前端轮询并显示创建中、完成、失败 |
| 模式一直切换未完成 | 两条旧预检查失败任务未释放，实际没有生成任何切换步骤 | V56 仅取消满足严格条件的旧任务；不重置已执行的步骤；补齐缺失 Agent 模式记录 |
| 模式失败回报 HTTP 500 | 失败结果没有组件字段，写入数据库非空字段时传入 null | 以 UNKNOWN 表示缺失组件状态，失败任务可正常降级并重试 |
| 真实命令永久 RUNNING | 旧 Agent 并行启停绕过结果持久化，后端 500 后丢失回报 | 启停复用持久化执行链，同机顺序执行；后端每次只租赁一条命令；结果重试不重复执行 |
| 独立环境文件可能互相影响 | 同用户不同独立环境共用 unbound 目录 | 新建独立环境按环境 ID 隔离目录；旧目录不搬迁、不删除 |
| 重复独立环境可创建 | 查询使用 `course_id = NULL` | 正确使用 IS NULL，按类型及独立环境名称检查重复，比赛环境同用户限一个 |
| 实训接口可误启动比赛环境 | 共用启动服务没有检查环境类型 | 普通实训入口拒绝比赛环境；比赛由模式阶段控制启动；参赛端重试只查询就绪状态 |
| 下课只关闭课堂记录 | 容器停止依赖浏览器后续批量请求 | 下课服务端提交停止；启动中的任务被停止请求替代，最终按先启后停收敛 |
| 上课失败仍显示上课中 | 未区分提交、就绪、失败 | 显示环境启动中、上课失败及失败数；比赛模式禁用上课按钮 |
| 缺失容器阻断同用户其他环境 | STOP 要求组件必须存在 | 缺失组件停止为幂等成功，并返回 MISSING；存在组件仍校验受管身份 |
| 单组件标注冷启动失败 | 外层 TCP 就绪早于内层 Docker/CVAT，认证立即初始化 | 加入有上限的内层认证就绪重试 |
| 管理首页指标栏出现模板碎片 | 内联模板属性引号冲突 | 修正模板字符串并在浏览器确认碎片消失 |
