# 实训环境与镜像流程基线

## 状态边界

- 镜像文件是平台当前可选镜像的唯一来源；推送历史只证明该文件曾成功下发，不直接生成模板选项。
- 模板保存组件、运行参数、镜像名称和版本配置，不绑定服务器；创建环境时再按目标 Agent 清单校验镜像。
- 环境创建只提交 `CREATE_*_TRAINING_ENVIRONMENT`，成功回报前保持 `CREATING`，成功后为 `STOPPED`；没有 Agent 回报不能显示成功。
- 一键上课提交 `START_*` 并锁定指定课堂环境；只有所有目标环境实际 RUNNING 才显示上课中，失败显示原因，管理员可下课后重试。
- 删除先取消同环境未完成命令，再提交 `DELETE_*`；Agent 成功后释放端口并删库，失败保留环境为 `DEGRADED/ERROR` 供重试。
- 比赛切换按阶段执行：进入前要求比赛环境创建就绪，先停止课程实训，再启动比赛环境；退出比赛只停止比赛环境，课堂会话同步关闭。
- Agent 命令按单机逐条租赁、串行执行并持久化结果；镜像下发上限为 3 小时，平台绝对回收为 3 小时 15 分钟。
- 远程终端走 Agent 命令通道；SSH 仅用于 Agent 远程部署，连接失败必须返回 bridge/SSH 的具体错误，不改变 Agent 在线状态。

## 发布验收

1. 上传并成功推送一个镜像；模板下拉只出现当前启用文件名，不出现历史标签。
2. 用目标服务器创建环境，确认 Agent 收到创建命令并实际产生容器；创建失败不得留下“已创建”状态。
3. 一键上课验证所有环境均为 `RUNNING` 后才显示就绪；下课由服务端提交停止，包含启动中的环境。
4. 删除环境验证容器删除回报、端口释放和数据库删除；模拟 Agent 离线验证页面可重试且不丢记录。
5. 比赛进入/退出验证阶段顺序和失败可重试；不允许跳过停止课程环境。
6. 镜像下发达到配置的截止时间后，验证任务失败且同 Agent 的环境命令可继续执行。
7. 远程终端验证 Agent 在线时可建立会话；SSH 部署验证用户名、端口、bridge 错误原样可见。

## 当前已修复

- 过期镜像部署任务不再因重复进度永久保持 `RUNNING`。
- 模板创建按当前 `image_file` 和成功推送记录校验，历史 `target_image` 不再直接作为模板来源。
